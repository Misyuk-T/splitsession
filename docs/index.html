SplitSession

Same site, separate logins.

A Chrome extension that works like Firefox containers: several accounts of one site stay signed in at once, in different tabs of one profile.

Download GitHub Chrome Web Store: not yet

Version 0.1, beta. MIT licence.

What it does

  • Containers. A name, a colour and a cookie jar each. Make them in the toolbar popup. Export and import as JSON; cookies stay out unless you tick the box.
  • Isolation. Cookies, localStorage, IndexedDB and more are kept apart per container. Links and popups opened from a container tab stay in it.
  • Tab groups. Each container is a Chrome tab group in its colour, synced both ways. Rename the group and you rename the container.
  • Domain rules. Always open a site in container X, or ask.
  • Restore. After a restart, Reopen closed tab or History, tabs return to their containers. A tab that cannot be matched with certainty waits for you in the popup and sends nothing to the site.
  • Strict mode, optional. Removes service workers so none can answer a container tab with your regular logins. Push notifications stop working.

Split view

Two accounts of one site in Chrome’s split view. A split pair of two containers leaves the container groups instead of being reopened, so each side keeps its login.

Lite / Full

One codebase, two builds. Lite is containers only. Full adds the optional local agent bridge. The bridge code is not compiled into Lite, and the Lite build fails if any of it, or a Full-only permission, ends up in the bundle.

AI agents (Full)

An optional local MCP server lets your own agent (Claude Code, Codex, Cursor and others) list your tabs with their containers and operate them: snapshots, trusted clicks and typing, screenshots, console and network, opening pages in a container.

Off by default, one all-or-nothing switch. While it is on, the agent can act in every tab, signed-in pages included.

npx splitsession-bridge install

Then turn on “Agent bridge” under Settings, For AI agents.

Install

Until the Chrome Web Store listing exists, install from a GitHub release (Lite or Full).

  1. Download and unzip splitsession-lite-<version>.zip or splitsession-full-<version>.zip from Releases.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked.
  4. Select the unzipped folder, then pin the toolbar button.

Limits & privacy

  • It separates accounts, nothing more. Not a privacy tool, not a sandbox. The HTTP cache, HTTP auth, browser fingerprint, saved passwords and history are shared. One residual hole is documented: same-origin frames and popups during navigation.
  • Beta. Tested against a local stand, not on many real sites. Some sites may notice two sessions from one browser.
  • Sends nothing anywhere. No account, analytics or telemetry; no network requests of its own. It asks for access to all sites because rewriting request headers per tab needs it. Data sits unencrypted in chrome.storage, like Chrome’s own cookies.
