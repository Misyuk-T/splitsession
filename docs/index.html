SplitSession

Same site, separate logins.

Firefox-style containers for Chrome. Keep several accounts of one site signed in at the same time, in different tabs of one profile. No second profile, no second browser.

Download from GitHub View on GitHub

Free, open source (MIT). Beta, version 0.1.

Why containers

Chrome profiles are too heavy for this job

A profile isolates everything, which is more than you need to be two people on one website.

1

A whole window per account

Each profile has its own extensions, bookmarks and history. You maintain all of them to keep a second login.

2

Switching gets old

Answering a client's account and going back to yours means switching profiles over and over, all day.

3

Agents see only one

An AI agent that drives “your browser” can see just one of your profiles at a time.

Containers isolate only what identifies you to a site, cookies and page storage, and leave the rest of the profile shared. You pick the account per tab, not per window.

Features

Everything a tab needs to be someone else

Containers

A name, a colour and a cookie jar each. Create, rename, recolour and delete them from the toolbar popup.

Cookie and storage isolation

Network cookies, localStorage, IndexedDB and more stay apart per container. Popups and links opened from a container tab stay in it.

Tab groups

Containers show up as Chrome tab groups in their own colour, kept in sync both ways. Rename a group and you rename the container.

Domain rules

“Always open this site in container X” or “ask me”, like Firefox's “Always open in”.

Strict mode

Optional. Removes service workers so none can answer a container tab with your regular logins. The price: push notifications.

Export and import

Containers and rules as a JSON file. Cookies stay out unless you tick a clearly marked box.

Split view

Two accounts, literally side by side

Put two accounts of one site in Chrome's split view. A split view of two containers leaves the container groups instead of being reopened, so each tab keeps its own login.

Handy for comparing a work account and a personal one, or checking what a customer sees while you stay signed in as admin.

Restore after restart

Tabs come back to their own accounts

Restart Chrome, use Reopen closed tab, History or a reopened tab group, and container tabs return to their containers.

  • Works with “Continue where you left off”.
  • A tab SplitSession cannot match with certainty is held back. It waits for you in the popup, and nothing is sent to the site until you choose.

Lite is not Full with the settings hidden: the agent code is not compiled into it, and the Lite build fails if any bridge code or Full-only permission ends up in the bundle.

AI agents Full edition

Let your agent use your tabs

An optional local MCP server lets your own agent (Claude Code, Codex, Cursor and others) list your Chrome tabs with their containers and operate them: snapshots, trusted clicks and typing, screenshots, console and network, opening pages in a container.

It is off by default and one all-or-nothing switch in Settings. While it is on, the agent can act in every tab, signed-in pages included.

$npx splitsession-bridge install

Then switch on “Agent bridge” under Settings › “For AI agents”.

Security and privacy

Honest about what it does and doesn’t do

  • It sends nothing anywhere.No account, analytics, crash reporting or telemetry. The extension makes no network requests of its own, and everything stays on your computer.
  • It separates accounts, nothing more.SplitSession is not a privacy tool and not a sandbox. It keeps logins of one site apart.
  • Why “all sites” access?Rewriting request headers per tab needs it, and it cannot know in advance which sites you will use.
  • Stored like Chrome's own cookies.Containers and cookie jars live in chrome.storage on your machine, unencrypted. Full-disk encryption is what protects both.
  • Not isolatedThe HTTP cache, HTTP auth, browser fingerprint, saved passwords and history. One known residual hole is documented, same-origin frames and popups during navigation.
  • Beta, not widely tested yetIt has unit and end-to-end tests against a local stand, but not many real sites. Some may notice two sessions from one browser.
